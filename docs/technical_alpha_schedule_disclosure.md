# Technical Alpha schedule disclosure

This file is the authoritative schedule disclosure for the 2026–27 Technical Alpha tester handoff.

- The fictional Technical Alpha league uses **8 fictional teams and an 84-game schedule per club**.
- The real 2026–27 NHL uses **32 teams and 84 games per club (42 home, 42 road)**.
- Matching game counts do **not** mean the Alpha reproduces the NHL scheduling matrix, opponent rotation, clubs, branding, or licensed league data.
- Tester-facing handoff material must say **84 games**. Any older Technical Alpha text that says the current pilot uses an 82-game schedule is stale and must not be distributed.
- The facilitator must include this limitation with the build until the pilot guide's older schedule wording is fully consolidated.

This is a disclosure/readiness clarification only. It does not change simulation, save, API, packaging, or UI behavior.
